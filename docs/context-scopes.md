# Context-Scopes

Welche Pfade bei welcher Aufgabe geladen werden. Die Tabelle wächst mit dem Code.

| Aufgabe | Relevante Pfade | Nicht nötig |
|---------|-----------------|-------------|
| Anforderungen klären | `docs/anforderungen/`, `docs/roadmap.md`, `docs/recherche/` | `.github/` |
| Architektur-Dokumente | `docs/`, insbesondere `docs/adr/`, `docs/anforderungen/README.md` | `.github/` |
| Arbeitsweise, Issues | `docs/issue-konventionen.md`, `.github/ISSUE_TEMPLATE/`, `CLAUDE.md` | `docs/recherche/` |
| CI und Prüfungen | `Makefile`, `scripts/`, `.github/workflows/`, `.github/dependabot.yml` | `docs/recherche/` |
