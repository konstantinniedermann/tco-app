# Context-Scopes

Welche Pfade bei welcher Aufgabe geladen werden. Die Tabelle wächst mit dem Code.

| Aufgabe | Relevante Pfade | Nicht nötig |
|---------|-----------------|-------------|

| Neue Funktion planen, Datenschutz | `docs/datenschutz.md`, `docs/datenschutzerklaerung.md`, `docs/anforderungen/anforderungen.md`, `docs/abklaerungen.md` | `docs/recherche/` |

| CI und Prüfungen | `Makefile`, `scripts/`, `.githooks/`, `.github/workflows/`, `.github/dependabot.yml` | `docs/recherche/` |
