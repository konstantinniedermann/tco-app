# Pläne und Specs (Geschichte)

Die Pläne und Specs in diesem Ordner sind Arbeitsmaterial früherer Vorgänge. Sie werden nicht
nachgeführt und zeigen den Stand ihres Datums, nicht die geltende Lage; einzelne Entwürfe
gehören zu Issues, die noch offen oder noch nicht gebaut sind. Was gilt, steht in der übrigen
Doku und im Code. Sie gehören darum nicht von vornherein in den Kontext einer Aufgabe (siehe
[Context-Scopes](../context-scopes.md)); wer ein offenes Issue aufnimmt, liest den Entwurf, den
das Issue nennt.
