# Pläne und Specs (Geschichte)

Die Pläne und Specs in diesem Ordner sind Arbeitsmaterial abgeschlossener Vorgänge. Sie werden
nicht nachgeführt und beschreiben den Code, wie er damals war, nicht die geltende Lage. Was
gilt, steht in der übrigen Doku und im Code. Sie gehören darum nicht in den Kontext einer
Aufgabe (siehe [Context-Scopes](../context-scopes.md)).
