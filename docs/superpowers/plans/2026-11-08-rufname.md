# Rufname Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mitglieder tragen im Profil freiwillig einen Rufnamen ein; App und die Verwaltungsbereiche Turnierleitung, Anlass-Antworten und Mitteilungen zeigen ihn vor dem amtlichen Namen. Mitgliederverwaltung, Auskunft und Brief bleiben amtlich.

**Architecture:** Neue Spalte `mitglied.rufname` ausserhalb von `Angaben` (wie `klassierung`). Ein reines Modul `src/lib/name.ts` (Browser und Server) entscheidet die Darstellung, eine Komponente `src/lib/ui/Name.svelte` zeigt sie. Der Server liefert an den betroffenen Stellen statt eines fertigen Strings die Namensteile.

**Tech Stack:** SvelteKit (Svelte 5), TypeScript, Drizzle/PostgreSQL, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-08-rufname-design.md` (Issue #67)

## Global Constraints

- Rufname: freiwillig, höchstens **10 Zeichen** (Grapheme, nach Trim), leer → `null`, Meldung «Höchstens 10 Zeichen.»
- Setzen/Ändern/Löschen nur das Mitglied selbst über das Profil; kein Admin-Weg.
- Darstellung: Rufname in normaler Schrift, dahinter amtlicher Name als `.leise`; kurze Textform «Hannes (Johannes Muster)»; ohne Rufname wie heute.
- Rufname gleich Vorname (ohne Gross-/Kleinschreibung) → Anzeige wie ohne Rufname.
- Amtlich bleiben: Mitgliederverwaltung (Liste, Detail, Rollen, Änderungsverlauf, Für Fairgate), Auskunft, Brief (Adresse und «Hoi Vorname»), Passkey-Anzeigename, Seiten ohne Login.
- Sortierung unverändert nach Nachname, Vorname.
- Hilfetext Profil: «Freiwillig. Unter diesem Namen sehen dich die anderen im Club.»
- Datenschutz- und Leitbild-Doku **vor** dem Code (Task 1).
- Keine neuen Dependencies. Svelte-Doku vor Svelte-Code über den Svelte-MCP-Server holen; `svelte-autofixer` auf jede geänderte Komponente.
- Testdaten erfunden; Commits einzeln gestagt, Präfixe `feat:`/`docs:`/`test:`.
- DB-Tests und E2E mit eigener Datenbank (`tests/hilfen/eigene-datenbank.ts` bzw. eigene `DATABASE_URL`), weil parallele Worktrees `mytco` teilen.

## Review Focus

- Rufname nur aus Leerzeichen → wird `null`, nicht `''` (Task 3, Test `leer und Leerzeichen werden null`).
- «hannes» als Rufname bei Vorname «Hannes» → keine Doppelung (Task 2, Test `gleich wie Vorname`).
- Emoji oder «Zoë» mit kombiniertem Zeichen → zählt als ein Zeichen; unsichtbare Zeichen werden abgelehnt (Task 2, Tests `zählt Grapheme`, `lehnt Steuerzeichen ab`).
- Admin speichert Angaben im Verwaltungsformular → Rufname bleibt unverändert (Task 3, Test `Admin-Angaben lassen Rufname stehen`).
- Langer amtlicher Name plus Rufname auf 390 px → bricht um, kein waagrechtes Scrollen (Task 8, E2E mit `pruefeBildschirm`).
